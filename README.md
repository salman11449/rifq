# رِفْق — رفيق الطمأنينة

تطبيق ويب عربي للذكر، مجاني بالكامل: بلا إعلانات، بلا حساب، بلا تتبّع.
كل شيء (الكود والخطوط والبيانات) داخل ملف واحد يعمل بلا إنترنت.

افتح الرابط من أي جهاز — لا يحتاج تثبيتًا.

- «إضافة إلى الشاشة الرئيسية» تعمل كتطبيق مستقل.
- بياناتك تبقى في جهازك وحده.

## الملفات
- `index.html` — التطبيق الكامل (نسخة من `refq.html`)
- `refq.html` — نفس الملف، للتحميل والمشاركة
- `sw.js` — العمل دون إنترنت
- `manifest.webmanifest` — بيانات التطبيق عند التثبيت
